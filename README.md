# No Fear Research Papers

A "No Fear Shakespeare" for research papers: the paper's own words on the left,
everyday English on the right, with interactive data slides where the paper makes a claim.

## Structure

- `index.html` — project home: the motivation + index of translated papers
- `papers/alphamissense/` — demo translation: Cheng et al., *Science* 2023
  (AlphaMissense — essentially an AI spell-checker for DNA typos), with
  interactive benchmark charts and a real-data PTEN variant explorer
  (2,391 swaps sliced from DeepMind's public 71M-variant release, CC BY-NC-SA 4.0, research use)
- `og-image.jpg` — link preview card

Built with Muse AI. Each translation is a single self-contained HTML file — no build step, no backend.
