# No Fear Research Papers

A "No Fear Shakespeare" for research papers: the paper's own words on the left,
everyday English on the right, with interactive data slides where the paper makes a claim.

## Demos

- **AlphaMissense, translated** (`index.html`) — Cheng et al., *Science* 2023.
  Side-by-side translation + interactive benchmark chart + real-data PTEN variant
  explorer (2,391 swaps sliced from DeepMind's public 71M-variant release, CC BY-NC-SA 4.0, research use).

Built with Muse AI. Each demo is a single self-contained HTML file — no build step, no backend.
